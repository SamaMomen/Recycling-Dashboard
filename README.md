# EcoSort — Smart Recycling Dashboard

Prototype dashboard for the environmental competition.

## Run

1. Install Python.
2. Open this folder in VS Code.
3. In the terminal run:

```bash
pip install -r requirements.txt
streamlit run app.py
```

The dashboard currently uses sample detection data for masks, gloves, yellow bags, and other waste.
Later, the numbers can be connected to the team's computer-vision/AI model.
